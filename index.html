Why Work With Me

Still a student, already shipping. Here is how I approach every build, from the first wireframe to the last detail.

I start with hierarchy, spacing, and rhythm before a single color lands. A page that reads well without styling will always read better with it.

Semantic HTML, predictable CSS, and JavaScript that stays readable a month later. I would rather write less and understand all of it.

Animation should guide attention, not compete for it. Every transition here has a job: reveal, respond, or reassure.

Each project is a deliberate step up from the last. New stack, new constraint, new detail to get right.
